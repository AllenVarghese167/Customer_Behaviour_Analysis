# Customer Behaviour Analysis

## 📊 Project Overview

This project analyzes customer shopping behavior using **Python, SQL, and Power BI**.

The project focuses on cleaning and preparing customer shopping data, performing exploratory data analysis, using SQL to answer business-related questions, and presenting the results through a Power BI dashboard.

* Power BI

---

## 🔄 Project Workflow

**Raw Data → Data Cleaning → Exploratory Data Analysis → SQL Analysis → Power BI Dashboard**

---

## 🐍 Python – Data Cleaning & EDA

Python and Pandas were used to clean and prepare the dataset for analysis.

The following steps were performed:

* Loaded the customer shopping dataset
* Examined the dataset using `info()` and `describe()`
* Checked for missing values
* Handled missing **Review Rating** values using the median rating within each product category
* Standardized column names
* Renamed `purchase_amount_(usd)` to `purchase_amount`
* Created an **age_group** column
* Converted purchase frequency categories into numerical day-based values
* Identified redundant columns
* Removed the `promo_code_used` column
* Exported the cleaned dataset to Excel

---

## 🗄️ SQL – Business Analysis

SQL was used to perform additional analysis on the cleaned customer shopping data.

The SQL queries focus on extracting useful information from the dataset and answering business-related questions.

The analysis includes queries for areas such as:

* Customer purchasing behavior
* Product category analysis
* Purchase amounts
* Customer segmentation
* Purchase frequency
* Ratings
* Subscription and discount behavior

The SQL queries are included in the project as a separate `.sql` file.

---

## 📊 Power BI Dashboard

Power BI was used to create an interactive dashboard based on the customer shopping data.

The dashboard allows the data to be explored through different visualizations, filters, and key metrics.

The dashboard focuses on:

* Customer behavior
* Product categories
* Purchase patterns
* Customer demographics
* Ratings
* Sales-related analysis
